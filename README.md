# KaijuEngine

A basic game engine written in Go.

## Project Structure

- `main.go` - Entry point for the engine
- `engine/` - Core engine components
- `game/` - Game logic and entities
- `rendering/` - Graphics and rendering system
- `input/` - Input handling
- `utils/` - Utility functions

## Getting Started

### Prerequisites
- Go 1.23 or higher

### Installation

```bash
go build -o KaijuEngine.exe
```

### Running

```bash
./KaijuEngine.exe
```
